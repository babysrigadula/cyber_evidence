# 🛡️ Cybercrime Investigation & Evidence Management System

A professional academic web interface for managing cybercrime investigation cases and digital evidence in a centralized workspace.

## 🌐 Live Demo

After publishing this project with **GitHub Pages**, your live website will be available at:

`https://babysrigadula.github.io/cyber_evidence/`


## 📌 Project Overview

The **Cybercrime Investigation & Evidence Management System** is designed to help authorized investigators organize cybercrime cases and maintain digital evidence records throughout an investigation.

The platform focuses on:

- Case registration and management
- Digital evidence documentation
- Evidence metadata
- SHA-256 hash recording and verification
- Chain-of-custody tracking
- Investigation activities and timeline
- Audit logging
- Role-based access
- Structured investigation reports

## ✨ Main Features

### 1. Case Management
Create, update, search and manage cybercrime investigation cases using unique case identifiers.

### 2. Evidence Management
Record evidence details such as evidence ID, source, collector, collection date and storage reference.

### 3. SHA-256 Integrity Verification
Store SHA-256 hash values and compare them when checking the integrity of digital evidence.

### 4. Chain of Custody
Maintain a chronological record of evidence transfers, including who released and received the evidence and when the transfer occurred.

### 5. Investigation Timeline
Record investigation activities, observations, findings and timestamps.

### 6. Role-Based Access
Support controlled access for roles such as:

- Administrator
- Investigator
- Forensic Analyst
- Evidence Custodian
- Supervisor

### 7. Audit Logs
Maintain an activity history to improve accountability and traceability.

### 8. Reports
Present case, evidence, integrity, custody and activity information in an organized report format.

## 🚀 Run Locally

1. Download or clone the repository.
2. Open the project folder.
3. Make sure `index.html`, `style.css`, and `script.js` are in the same folder.
4. Double-click `index.html`.

The website will open in your browser.

For development, you can also open the folder in **Visual Studio Code** and use a local web server such as Live Server.

## ☁️ Deploy on GitHub Pages

1. Create a GitHub repository named:

```text
cybercrime-investigation-system
```

2. Upload:

```text
index.html
style.css
script.js
README.md
```

3. Open:

**Repository → Settings → Pages**

4. Under **Build and deployment**, select:

```text
Source: Deploy from a branch
Branch: main
Folder: / (root)
```

5. Click **Save**.

6. Wait for GitHub Pages to publish the website.

Your live URL will follow this format:

```text
https://YOUR-GITHUB-USERNAME.github.io/cybercrime-investigation-system/
```

## ⚠️ Academic Prototype Notice

This project is an academic prototype/interface. It should not be treated as a production forensic evidence platform without appropriate security controls, legal procedures, authentication, secure storage, access management, logging, validation and organizational approval.

A matching SHA-256 hash supports an integrity check, but a hash alone does not establish the origin, authenticity or lawful acquisition of evidence.
